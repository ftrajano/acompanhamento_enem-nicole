2. Meia-vida — o padrão nº 1

Não use fórmula. Conte metades.
1 meia-vida → \(\frac{1}{2}\) · 2 → \(\frac{1}{4}\) · 3 → \(\frac{1}{8}\) · 4 → \(\frac{1}{16}\) · \(n\) → \(\frac{1}{2^n}\)

Do tempo para a fração: quantos períodos couberam? Corte pela metade essa quantidade de vezes.
Da fração para o tempo: quantas metades a fração representa? Multiplique pela meia-vida.

Modelo (C14, ENEM 2020): meia-vida 5 730 anos, restou \(\frac{1}{8}\) → 3 metades → \(3 \times 5\,730 = 17\,190\) anos.

⚑ Erro clássico: multiplicar pelo denominador da fração (\(8 \times 5\,730\)) em vez de contar as metades (3).

3. Logaritmo é uma pergunta

\(\log_{10} N\) pergunta: “10 elevado a quanto dá \(N\)?” (sem base escrita = base 10)

\(\log 1\)\(\log 10\)\(\log 100\)\(\log 1000\)\(\log 10^n\)
0123\(n\)

Valores que o ENEM costuma fornecer: \(\log 2 \approx 0{,}30\) · \(\log 3 \approx 0{,}48\) · \(\log 5 \approx 0{,}70\) · \(\log 7 \approx 0{,}85\).

4. As três propriedades

PropriedadeEm palavrasExemplo
\(\log(ab) = \log a + \log b\)produto vira soma\(\log 10 = \log 2 + \log 5\)
\(\log\frac{a}{b} = \log a - \log b\)divisão vira subtração\(\log 5 = \log 10 - \log 2\)
\(\log a^n = n\log a\)expoente desce\(\log 8 = 3\log 2 = 0{,}90\)
Quando o enunciado dá valores de log, é para você combiná-los com estas propriedades — nunca para multiplicar entre si.

5. Potências de 10 na divisão

\(\frac{10^{a}}{10^{b}} = 10^{a-b}\) — subtraia os expoentes, com o sinal.

Modelo (decibel, ENEM 2023): \(N = 10\log\frac{I}{I_0}\), com \(I = 10^{-7}\) e \(I_0 = 10^{-12}\):
\(\frac{10^{-7}}{10^{-12}} = 10^{-7-(-12)} = 10^{5}\) → \(N = 10 \times 5 = 50\) dB.

⚑ Cuidado com o sinal negativo no expoente de baixo: \(-7 - (-12) = +5\), não \(-19\).

6. Assíntota: \(f(t) = a + c\,b^{\,t}\) com \(0
\(a\) = valor final (para onde estaciona; o "piso" do gráfico)
\(a + c\) = valor inicial (em \(t = 0\))

Modelo (resfriamento, ENEM 2024): \(T(t) = a + 80b^{\,t}\), água fervendo.
Em \(t=0\): \(a + 80 = 100 \Rightarrow a = 20\) (temperatura ambiente).
Se em \(t=10\) tem-se \(T=60\): \(80b^{10} = 40 \Rightarrow b^{10} = 0{,}5 \Rightarrow b = (0{,}5)^{1/10}\).

⚑ O \(a\) NÃO é a temperatura inicial. É a final. A inicial é \(a + c\).

Para desfazer um expoente \(n\), eleve a \(\frac{1}{n}\).

8. Roteiro na hora da prova

1) É soma fixa (linear) ou multiplicação fixa (exponencial)?
2) Se for decaimento pela metade: quantas metades?
3) Se tiver log: reescreva o número como potência de 10 e o log devolve o expoente.
4) Se a fórmula for \(a + c\,b^t\): o \(a\) é o final, o \(a+c\) é o inicial.
